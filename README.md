# Sahl Camera · كاميرا سهل

A fast, lightweight, privacy-respecting camera app for Android 11+, from the Sahl apps family.

## Features
- **Instant startup & fast shutter**: Launches directly into a `SurfaceView` viewfinder with Zero-Shutter-Lag (`ZSL`) photo capture.
- **HD photos & vendor extensions**: One-tap toggle between **Fast** and **Quality**, with automatic support for device **HDR** and **Night** CameraX extensions when exposed by hardware.
- **HD & 4K video**: Record `720p`, `1080p Full HD`, or `4K UHD` video with pause/resume, torch toggle, and stabilization.
- **Clean controls**: Tap-to-focus with exposure slider, pinch-to-zoom + quick zoom pills, timer (`3s` / `10s`), composition grids (`3×3` / `Golden Ratio`), and volume-button shutter.
- **System camera integration**: Supports `ACTION_IMAGE_CAPTURE` and `ACTION_VIDEO_CAPTURE` so other apps can launch Sahl Camera directly.
- **Privacy-first**: GPS location EXIF is off by default; zero analytics or background tracking.
- **In-app updates** from GitHub Releases.
- Arabic and English, light and dark settings.

## Install
